Coupons

Erstelle Rabattcodes für Shop-, STANK- und Materialbestellungen. Kunden geben den Code vor dem Absenden ein; der Endpreis wird serverseitig geprüft.

Coupon erstellen

3–32 Buchstaben, Zahlen oder Bindestriche. Codes sind nicht groß-/kleinschreibungsabhängig.
Leer lassen, wenn der Code unbegrenzt oft nutzbar sein soll.

Gespeicherte Coupons

Jede eingegangene Bestellung zählt als eine Einlösung. Deaktivierte oder aufgebrauchte Codes können nicht mehr eingelöst werden.
